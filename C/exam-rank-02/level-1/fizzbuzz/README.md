Nome da atividade  : fizzbuzz
Arquivos esperados : fizzbuzz.c
Funções permitidas : write
Proibições e normas: for, switch, case, linhas com mais de 80 colunas... Para ver todas as proibições, consulte a norm.
--------------------------------------------------------------------------------

Escreva um programa que imprima os números de 1 a 100, cada um separado por uma quebra de linha.

Se o número for um múltiplo de 3, imprima 'fizz' em vez disso.

Se o número for um múltiplo de 5, imprima 'buzz' em vez disso.

Se o número for tanto um múltiplo de 3 quanto de 5, ele imprime 'fizzbuzz' em vez disso.

Exemplo:

$>./fizzbuzz
1
2
fizz
4
buzz
fizz
7
8
fizz
buzz
11
fizz
13
14
fizzbuzz
[...]
97
98
fizz
buzz
$>
