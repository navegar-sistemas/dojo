Nome da atividade  : reverse_bits
Arquivos esperados : reverse_bits.c
Funções permitidas : 
Proibições e normas: for, switch, case, linhas com mais de 80 colunas... Para ver todas as proibições, consulte a norm.
--------------------------------------------------------------------------------

Escreva uma função que recebe um byte, inverte-o bit a bit (como no exemplo) e retorna o resultado.

Sua função deve ser declarada da seguinte forma:

unsigned char	reverse_bits(unsigned char octet);

Exemplo:

  1 byte
_____________
 0100  0001
     ||
     \/
 1000  0010
