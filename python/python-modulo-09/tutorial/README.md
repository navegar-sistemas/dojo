# Tutorial do Cosmic Data

Site em Docusaurus com o passo a passo dos três exercícios de modelos e validação de dados com
Pydantic.

```sh
npm install
npm start          # servidor local com recarga automática
npm run build      # site estático em build/
npm run serve      # serve o build/
```

As páginas ficam em `docs/`, uma pasta por parte. A ordem vem do `_category_.json` de cada pasta
e do `sidebar_position` de cada página. Os diagramas são blocos Mermaid escritos nas próprias
páginas.
