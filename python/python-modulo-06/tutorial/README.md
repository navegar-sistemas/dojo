# Tutorial do The Codex

Site em Docusaurus com o passo a passo das quatro partes do projeto de módulos, pacotes e imports
em Python.

```sh
npm install
npm start          # servidor local com recarga automática
npm run build      # site estático em build/
npm run serve      # serve o build/
```

As páginas ficam em `docs/`, uma pasta por parte. A ordem vem do `_category_.json` de cada pasta
e do `sidebar_position` de cada página.

Os diagramas são blocos `mermaid` dentro das próprias páginas; o site não tem imagens geradas à
parte.
