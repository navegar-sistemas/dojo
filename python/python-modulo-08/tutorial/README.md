# Tutorial do The Matrix

Site em Docusaurus com o passo a passo dos três exercícios de ambientes virtuais, gerenciamento
de pacotes (pip e Poetry) e configuração por variáveis de ambiente em Python.

```sh
npm install
npm start          # servidor local com recarga automática
npm run build      # site estático em build/
npm run serve      # serve o build/
```

As páginas ficam em `docs/`, uma pasta por parte. A ordem vem do `_category_.json` de cada pasta
e do `sidebar_position` de cada página.

O gráfico de `static/img/ex1/matrix_analysis.png` é o arquivo que o programa do exercício 1 gera
(`ex1/loading.py`), copiado como está.
