# Tutorial do FuncMage

Site em Docusaurus com o passo a passo dos cinco exercícios de programação funcional em Python:
lambdas, funções de ordem superior, closures, `functools` e decoradores.

```sh
npm install
npm start          # servidor local com recarga automática
npm run build      # site estático em build/
npm run serve      # serve o build/
```

As páginas ficam em `docs/`, uma pasta por parte. A ordem vem do `_category_.json` de cada pasta
e do `sidebar_position` de cada página.

Os diagramas são blocos Mermaid escritos nas próprias páginas; o site não tem imagens geradas.
