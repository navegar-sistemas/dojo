# Tutorial do The Codex

Site em Docusaurus com o passo a passo dos cinco exercícios de ambientes virtuais, dependências,
configuração por variáveis de ambiente e imports em Python.

```sh
npm install
npm start          # servidor local com recarga automática
npm run build      # site estático em build/
npm run serve      # serve o build/
```

As páginas ficam em `docs/`, uma pasta por parte. A ordem vem do `_category_.json` de cada pasta
e do `sidebar_position` de cada página. Os diagramas são escritos em Mermaid, dentro das próprias
páginas.
